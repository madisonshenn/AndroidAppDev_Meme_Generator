# AndroidAppDev_Meme_Generator
-Android App that generates custom meme

### Description:
The project implements a meme generator application that allows users to create custom memes through an Android mobile app. The system consists of a mobile application, a RESTful web service that communicates with a third-party API (Meme Maker API: https://api.memegen.link ), and a web-based dashboard for analytics and logging
